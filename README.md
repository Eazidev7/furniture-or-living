# Furniture or Living

Furniture e-commerce storefront — collection browsing, cart, multi-step
checkout, order enquiries, dark mode, and an admin dashboard.

- **Frontend:** vanilla HTML/CSS/JS
- **Backend:** Supabase edge functions (`supabase/functions/admin-api`), Postgres (`supabase/schema.sql`)

**Live:** https://eazidev7.github.io/furniture-or-living/
